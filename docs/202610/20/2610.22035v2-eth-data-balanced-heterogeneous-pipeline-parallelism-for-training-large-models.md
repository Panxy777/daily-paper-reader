## 摘要
当前面向大模型的异构感知训练系统通过在各流水线阶段分配不等的层数来平衡工作负载，该策略旨在通过一种独特的流水线配置来均衡执行时间。然而，该方法未能解决关键的内存约束问题，并且其平衡粒度本质上较粗。本文提出异构流水线并行（Heterogeneous Pipeline Parallelism, HPP），一种能够在异构流水线之间实现高效且细粒度数据平衡的新方法。为解决 HPP 的关键挑战，即为寻找最优配置而带来的高昂搜索开销，以及非对称 All-Reduce 导致的高通信开销，我们设计了 ETH 训练系统。ETH 采用分层工作负载平衡框架，联合优化异构流水线之间以及单个流水线阶段内部的平衡。为缓解非对称通信成本，ETH 实现了分块梯度聚合。此外，它集成了专用优化，可显著降低 HPP 配置搜索开销。评估表明，与最先进的系统相比，ETH 实现了最高 2 倍的训练加速，同时将配置生成开销最多降低 56 倍。代码可在 https://github.com/YuMJie/ETH 获取。

## Abstract
Current heterogeneity-aware training systems for large models balance workloads by assigning unequal numbers of layers across pipeline stages, a strategy aimed at equalizing execution time through a unique pipeline configuration. However, this approach fails to address critical memory constraints and suffers from inherently coarse balancing granularity. In this paper, we propose Heterogeneous Pipeline Parallelism (HPP), a novel approach enabling efficient and fine-grained data balance across heterogeneous pipelines. To address HPP's key challenges, prohibitive search overhead for optimal configurations and high communication overhead from asymmetric All-Reduce, we design the ETH training system. ETH employs a hierarchical workload balance framework that jointly optimizes balance across heterogeneous pipelines and within individual pipeline stages. To mitigate asymmetric communication costs, ETH implements block-wise gradient aggregation. Furthermore, it integrates specialized optimizations that dramatically reduce HPP configuration search overhead. Evaluations demonstrate ETH achieves up to 2x training speedup while reducing configuration generation overhead by up to 56x compared to state-of-the-art systems. The code is available at https://github.com/YuMJie/ETH.
