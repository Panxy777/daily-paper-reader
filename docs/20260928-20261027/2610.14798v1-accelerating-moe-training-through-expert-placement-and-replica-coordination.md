## 摘要
稀疏激活的专家混合（MoE）模型的分布式训练常常受限于由动态 token 路由引起的工作负载不均衡和全对全（A2A）通信。现有的 token 去重、专家放置和副本技术可以缓解这些瓶颈，但未能联合刻画它们各自不同的负载语义。在分层 token 去重下，通信在每个层级对每个目标组仅计数每个 token 一次，而专家计算则处理每个 token-专家分配。采用副本时，这两种开销共同取决于物理布局和 token 到副本的映射，因此分别优化是次优的。我们提出 PlaceMoE 来解决这种耦合。首先，我们为分布在 P 个设备上的 E 个专家建立专家布局与源感知的 token 到副本映射的联合优化，同时考虑分层通信流量和专家计算负载。其次，我们开发了一个求解器，结合共选择感知的专家分组、用于副本分配的有界动态规划，以及布局和映射的交替细化。第三，PlaceMoE 将副本梯度同步与注意力反向传播重叠。我们在 32-GPU 集群和 64-NPU 集群上使用 Qwen3-VL 和 DeepSeek-V3 评估 PlaceMoE。实验结果表明，与最先进的训练框架 VeOmni 相比，PlaceMoE 在 A2A 通信上实现了最高 6.94 倍的加速，在端到端训练上实现了 1.74-2.33 倍的加速。

## Abstract
Distributed training of sparsely activated mixture-of-experts (MoE) models is often bottlenecked by workload imbalance and all-to-all (A2A) communication induced by dynamic token routing. Existing token deduplication, expert placement, and replication techniques alleviate these bottlenecks but do not jointly capture their distinct load semantics. Under hierarchical token deduplication, communication counts each token once per destination group at each hierarchy level, whereas expert computation processes every token-expert assignment. With replication, both costs depend jointly on physical layout and token-to-copy mapping, making separate optimization suboptimal. We present PlaceMoE to address this coupling. First, we formulate the joint optimization of expert layout and source-aware token-to-copy mapping for E experts distributed across P devices, accounting for both hierarchical communication traffic and expert-compute load. Second, we develop a solver that combines co-selection-aware expert grouping, bounded dynamic programming for replica allocation, and alternating refinement of layout and mapping. Third, PlaceMoE overlaps replica-gradient synchronization with attention backward. We evaluate PlaceMoE on a 32-GPU cluster and a 64-NPU cluster using Qwen3-VL and DeepSeek-V3. Experimental results show that PlaceMoE achieves up to a 6.94x speedup in A2A communication and 1.74-2.33x speedups in end-to-end training over the state-of-the-art training framework VeOmni.

## 1. 核心问题与研究动机

- **背景**：稀疏激活的 MoE 模型通过 top-k 路由扩展参数规模，但在专家并行（EP）下，动态 token 路由导致严重的**负载不均**与**全对全（A2A）通信瓶颈**，限制分布式训练的可扩展性。
- **现有三类系统级技术各有局限**：
  - **专家交换（swap）**：需要运行时状态迁移与在线规划，开销可能抵消负载均衡收益。
  - **专家复制（replication）**：副本需在每次优化器更新前聚合梯度，增加梯度通信，削弱计算均衡带来的收益。
  - **Token 去重（hierarchical deduplication）**：使通信与计算具有**不同的负载语义**——通信在每个层级对每个目标组只计 token 一次（逻辑 OR），而计算必须执行每个 token–专家分配（非去重）。
- **核心矛盾**：在分层去重 + 副本场景下，通信开销与计算开销**共同取决于**物理专家布局 $L$ 与源感知的 token 到副本映射 $M$。论文用图 1 给出反例：两种路由模式每专家/每 rank 计算负载完全相同，但 token–专家共现不同，导致去重后节点间流量不同，说明**聚合负载统计无法刻画去重通信**。图 3 进一步展示布局与映射在通信复用和计算均衡之间的冲突。
- **核心问题**：给定 $P$ 个 EP rank，如何联合确定 $L$ 与 $M$，在消除 A2A 冗余传输、保证每个 token–专家分配只执行一次的同时，均衡通信与计算负载。

## 2. 方法论

### 2.1 核心思想
将**副本分配、分层专家放置、源感知 token 到副本映射**三者联合建模，用标定的“去重分层通信代价 + 非去重专家计算代价”作为目标，通过结构化搜索（而非指数枚举）求解，并在运行时以查找表和异步重优化落地。

### 2.2 性能模型
- **通信**：α–β 模型 $T_h(m)=\alpha_h+\beta_h m$；同步集合通信按**最慢参与者**建模，分层代价为
  $C^{(p)}_{\text{comm}}=\sum_{h=1}^{H}\left(\alpha_h+\beta_h\rho_{p,h}\max_{g\in G_h}U_{p,h,g}\right)$，总通信为 4 个阶段（前向/反向 dispatch 与 combine）之和。
- **计算**：$C_{\text{comp}}=\gamma\max_{r\in R}A_r+\delta$，其中 $A_r$ 为 rank $r$ 上**非去重**的分配 token 数。
- 去重负载：$z_{t,h,g}(L,M)=\bigvee_{e\in E_t}\mathbf{1}[\phi_h(\pi(M(r_t,e)))=g]$，$U_{h,g}=\sum_t z_{t,h,g}$。

### 2.3 问题形式化
- 决策变量：$L:\bigcup_r S_r\to E\cup\{\varnothing\}$，$M:R\times E\to\bigcup_r S_r$。
- 目标：$J_D(L,M)=\frac{1}{|D|}\sum_{Q\in D}[C_{\text{comm}}+C_{\text{comp}}]$，在 profiled 路由快照上取平均并最小化。
- 约束：$M$ 必须选有效副本、每 rank 容量约束、每专家至少 1 个副本、额外副本总数恰为预算 $B$。

### 2.4 求解流程（算法 1 与算法 2）
1. **Profiling 与标定**：采集 token 级路由快照 $D$；微基准回归拟合 $(\alpha_h,\beta_h)$，前 3 步拟合 $(\gamma,\delta)$。
2. **需求与亲和统计**：$d_{r,e}$（源 rank 对专家的分配需求）、$a_{r,e,f}$（专家共选择亲和），用于生成候选而非最终评估。
3. **容量约束亲和划分（算法 1）**：谱嵌入 → K-means → 线性分配满足容量 → 贪心跨组交换；目标
   $J^{(h)}_{\text{part}}=-\omega_h\sum_{i<j}a_{i,j}\mathbf{1}[y_i=y_j]+\gamma\max_g\frac{\sum_{i:y_i=g}d_i}{p_g}$，第一项奖励通信复用，第二项惩罚计算热点。
4. **副本数量选择**：$B=uE+b$，$q=\gcd(E,b)$，对逻辑专家分组，用**有界动态规划**（TopKalloc，式 13）保留多个候选分配，避免仅按需求排序丢弃更优解。
5. **初始化 $L_0$ 与 $M_0$**：副本统计均匀分摊；先跨节点、后节点内两级划分；最大权匹配映射到物理组；按需求降序贪心选择节点本地副本。
6. **交替精化**：
   - 固定 $M$ 更新 $L$：把统计聚合到被选物理副本（式 15–16），再做两级划分与匹配。
   - 固定 $L$ 更新 $M$：按需求降序逐项贪心，式 (20) 综合通信奖励（与共选专家共享目标组 + 源局部性）与投影峰值计算惩罚。
7. **复杂度**：算法 1 为 $O(N^3)$；布局更新 $O(S^3)$；映射扫描保守上界 $O(PEHS)$，均为多项式时间，替代指数级联合搜索。

### 2.5 运行时机制
- $M$ 实现为**查找表**，刷新无需迁移专家状态；$L$ 更新需迁移专家参数与优化器状态，按源–目的 rank 打包批量 P2P，全部就绪后**原子切换**。
- 优化器在独立 CPU 进程**异步**运行，训练不中断。
- **副本梯度同步与同层注意力反向重叠**（图 4，独立流 S3），同步尾部在全局梯度范数计算前等待。
