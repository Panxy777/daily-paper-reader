## 摘要
大规模分布式训练使集合通信日益受带宽限制。在现代 GPU 集群中，NCCL 等通信库在 NVLink、InfiniBand 和以太网等异构互连上实现包括 AllReduce 在内的集合操作，因此高效利用可用网络带宽成为核心系统挑战。ForestColl 表明，此类网络结构上的集合通信可用分数树打包建模；其可扩展的多项式时间构造针对 AllGather 开发，而 AllReduce 通过组合 AllGather 与 ReduceScatter 获得。我们提出 DualColl，直接面向带宽受限的 AllReduce。在基于树的 AllReduce 模型下，DualColl 采用 Garg--Könemann 风格的乘法权重算法，并且对任意 $0<ε<1$，计算出一个可行调度，其吞吐量至少为最优 AllReduce 吞吐量的 $(1-ε)^2$。其关键组件是一个精确的最小成本集合树预言机，将物理链路对偶价格投影到参与 rank 的逻辑图上，从而将每次迭代归约为最短路径计算后接最小生成树。我们进一步将该框架扩展到本地等下一跳包喷洒路由，以及没有显式逐树带宽控制的网络。针对后者，我们引入树耦合的最大最小带宽共享模型，并证明树复制能以可证明的精度-复杂度权衡逼近显式分数分配。最后，我们将分数树打包框架扩展到更多集合操作和多个并发集合组。

## Abstract
Large-scale distributed training increasingly makes collective communication bandwidth-bound. In modern GPU clusters, communication libraries such as NCCL implement collectives including AllReduce over heterogeneous interconnects such as NVLink, InfiniBand, and Ethernet, making efficient use of available network bandwidth a central systems challenge.   ForestColl showed that collective communication on such fabrics can be formulated using fractional tree packing; its scalable polynomial-time construction is developed for AllGather, with AllReduce obtained by composing AllGather and ReduceScatter. We present DualColl, which targets bandwidth-bound AllReduce directly. Under the tree-based AllReduce model, DualColl applies a Garg--Könemann-style multiplicative-weights algorithm and, for any $0<ε<1$, computes a feasible schedule whose throughput is at least $(1-ε)^2$ of the optimal AllReduce throughput. Its key component is an exact minimum-cost collective-tree oracle that projects physical-link dual prices onto a logical graph of participating ranks, reducing each iteration to shortest-path computations followed by a minimum spanning tree.   We further extend the framework to local equal-next-hop packet-sprayed routing and to networks without explicit per-tree bandwidth control. For the latter, we introduce a tree-coupled max-min bandwidth-sharing model and show that tree duplication approximates an explicit fractional allocation with a provable accuracy-complexity tradeoff. Finally, we extend the fractional-packing framework to additional collective operations and multiple concurrent collective groups.

## 1. 核心问题与研究动机

- **背景**：大规模分布式训练（数据并行、张量并行、流水线并行、专家并行、分布式推理）中，AllReduce 等集合通信日益成为**带宽受限**的瓶颈。GPU 集群通过 NCCL 等库在 NVLink/NVSwitch、InfiniBand、以太网等异构互连上实现集合操作，节点内链路远快于节点间链路，且网络层级存在不同程度的超售，因此需要**拓扑感知的高吞吐调度**。
- **已有基础**：ForestColl 将集合通信建模为**分数树打包**（fractional tree packing），但其可扩展的多项式时间构造是针对 **AllGather** 开发的，AllReduce 则通过“AllGather + ReduceScatter”组合得到。
- **核心缺口**：这种组合对 AllReduce **不保证最优**。论文附录 A 构造了一个 5 rank 路径拓扑反例：AllGather 最优树集（聚合带宽 4）组合成 AllReduce 后受链路 1–2 双向叠加负载限制，只能达到约 10/3，而直接采用路径树的 AllReduce 可达 4。
- **论文目标**：DualColl **直接面向带宽受限 AllReduce**，在分数树打包框架下给出首个（据作者所知）具有可证明近优保证的多项式时间算法。

## 2. 方法论

### 2.1 建模基础

- 物理网络建模为有向图 $G=(V\cup S,E)$，$V$ 为 rank，$S$ 为交换机，每条有向边容量 $C_e$；全双工链路用两条反向有向边表示，且假设两方向容量相等。
- **基于树的 AllReduce**：数据分片沿逻辑树向根归约，再从根沿同一棵树广播。论文第 3 节证明：在调度器单路径路由、双向等容的全双工网络下，**树形调度不损失吞吐**（定理 2.1/3.7），因此树打包的最优值 OPT 就是 AllReduce 的最优吞吐。
- 分数树打包 LP：
  $$\max \sum_{T\in\mathcal{S}}\lambda_T \quad \text{s.t.}\quad \sum_{T\in\mathcal{S}}A_{e,T}\lambda_T\le C_e,\ \lambda_T\ge 0$$
  其中 $A_{e,T}$ 是树 $T$ 单位带宽在物理边 $e$ 上的容量消耗。
- 通过稳态流水线解释与完成时间下界（引理 2.2），证明**最大化聚合树带宽等价于最小化完成时间**，数据按 $\lambda_T$ 比例分片可实现最优。

### 2.2 Garg–Könemann 乘性权重框架

- 为每条物理边维护正价格 $y_e$，初始化 $y_e=\gamma/C_e$，$\gamma=(1+\epsilon)((1+\epsilon)m)^{-1/\epsilon}$。
- 迭代流程：
  1. 调用**最小费用集体树预言机**，得到最小化 $\sum_e A_{e,T}y_e$ 的树 $T^\star$；
  2. 计算瓶颈增广量 $\Delta=\min_{e:A_{e,T^\star}>0} C_e/A_{e,T^\star}$；
  3. 增加 $\lambda_{T^\star}\leftarrow\lambda_{T^\star}+\Delta$；
  4. 对所用边乘性提价 $y_e\leftarrow y_e(1+\epsilon A_{e,T^\star}\Delta/C_e)$；
  5. 当对偶长度 $D(y)=\sum_e C_e y_e\ge 1$ 时停止，最后统一缩放得到可行解。

### 2.3 精确最小费用集体树预言机（核心创新）

- 在路由可分离假设下，逻辑边 $\{u,v\}$ 的两个方向可独立选最短路，投影权重为
  $$W_{\{u,v\}}=d_y(u,v)+d_y(v,u)$$
  即在当前对偶价格下的双向最短路径距离之和。
- 构造仅含参与 rank 的**逻辑投影图** $G_R$（交换机不显式出现，只通过路径代价体现），对其求**最小生成树**（Prim，$O(n^2)$），并为每条逻辑边记录双向最短路径。
- 定理 4.1 证明该投影 + MST 恰好返回全局最小对偶费用的路由集体树，避免枚举指数多的候选树。
- 单次预言机复杂度 $O(n(|E|+N)\log N+n^2)$；总复杂度
  $$O\!\left(\frac{|E|\log|E|}{\epsilon^2}\left[n(|E|+N)\log N+n^2\right]\right)$$

### 2.4 近似保证

- 定理 4.2：对任意 $0<\epsilon<1$，返回可行分数树打包满足 $\sum_T\hat\lambda_T\ge(1-\epsilon)^2\,\mathrm{OPT}$。

### 2.5 扩展一：包喷洒路由

- 本地等下一跳包喷洒下，逻辑边反向不再镜像负载，故简单树不再最优；打包变量改为**共享根的 in-tree + out-tree 对**。
- 预言机对每个候选根分别求最小权 in-arborescence 与 out-arborescence（Chu–Liu/Edmonds，$O(n^2)$），取 $n$ 个根中最优，单次预言机 $O(n(N+|E|)+n^3)$。
- 投影权重通过**目标节点为根的期望代价动态规划**计算：$D_v(c)=\frac{1}{|\Gamma_v(c)|}\sum_{z\in\Gamma_v(c)}(y_{(c,z)}+D_v(z))$，每轮 $O(n(N+|E|))$。

### 2.6 扩展二：树耦合最大最小公平与树复制

- 真实网络不提供显式逐树带宽控制，论文引入**树耦合 max-min 公平**模型：一棵树的任一组成流被瓶颈后，整棵树被钳制到同一速率；瓶颈比推广为 $B^\star=\min_e C_e^{\text{rem}}/\sum_{F\in\mathcal{F}_{\text{active}}}p_e(F)$。
- 定理 5.2 证明该水填充过程在可行树速率多面体（具有 free-disposal 性质）上给出 max-min 公平分配。
- **树复制**：按 $m_i(X)=\lfloor a_i/X\rfloor$ 复制树 $T_i$，选满足 $\sum_i\lfloor a_i/X\rfloor\ge yk$ 的最大 $X^\star$（算法 3 用最大堆扫描断点，$O(yk\log k)$）。
- 定理 5.6：复制数 $yk\le\sum_i m_i\le yk+k-1<(y+1)k$，保证聚合带宽相对显式分配的损失为 $1+(k-1)/(yk)$；取 $y\approx 1/\mu$ 可使近似因子不超过 $1+\mu$。
- 定理 5.7：端到端（包喷洒 + 树复制）保证 $(1-\epsilon)^3\mathrm{OPT}$，总时间含 $1/\epsilon^3$ 的复制项。

### 2.7 扩展三：其他集合操作与多并发组

- **AllGather**：目标为 max-min，利用引理 6.1 将 max-min 目标等价转化为“每个根各取一棵树”的 **n-tuple 打包**；预言机改为每个根求最小 out-arborescence。
- **ReduceScatter**：直接求解（不靠 AllGather 反转，因为包喷洒下反转不保持分流比例），预言机改为 in-arborescence。
- **多并发 AllReduce 组**：最大化总带宽时每轮返回各集合中绝对最小权树；最大化最慢组时用 k-tuple 打包，预言机对每组独立求树并返回并集，复杂度乘 $k$。

## 6. 主要结论与发现

- 在树形 AllReduce 模型下，**树形调度不损失吞吐**（定理 2.1/3.7），使分数树打包成为 AllReduce 的精确抽象。
- DualColl 是首个对带宽受限 AllReduce 给出**多项式时间、$(1-\epsilon)^2$ 近优保证**的算法（交换拓扑）。
- 精确预言机可通过“对偶价格投影 + MST/最小树形图”实现，避免枚举指数多候选树。
- 包喷洒下需以“in-tree/out-tree 对”为打包变量；结合树复制与树耦合 max-min 公平，端到端保证为 $(1-\epsilon)^3\mathrm{OPT}$。
- 树复制可在无显式逐树带宽控制的网络中逼近任意分数分配，近似因子 $1+(k-1)/(yk)$ 随复制规模 $y$ 趋于 1。
- 复杂度上优于 ForestColl 的 $O(n^8)$，并扩展到 AllGather、ReduceScatter 和多并发集合组。

## 7. 优点
