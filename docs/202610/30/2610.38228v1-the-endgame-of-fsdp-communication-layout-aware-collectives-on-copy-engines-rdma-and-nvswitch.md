## 摘要
全分片数据并行（FSDP2）将参数和梯度维护为逐参数张量，而其集合通信路径却作用于扁平的、以 rank 为主序的缓冲区。在这些布局之间转换时，需要将 all-gather 输出拷贝到参数存储中，并将梯度打包进全组 fp32 缓冲区。在每 GPU 8K token 的 Llama-3.1 70B 训练中，仅布局转换就占单步时间的 6.4%。通信内核带来第二项开销：默认的 NCCL reduce-scatter 可使原本能在单个 wave 内完成的并发 GEMM 变慢 69%。我们提出 TIDE，一组基于公开 NCCL 2.31+ API 构建的零拷贝集合通信。TIDE 保留 FSDP2 的逐参数存储与计算内核，同时将布局放置融入集合通信寻址。TIDE-AG 使用 NVSwitch 组播和带节拍的递归倍增 RDMA 将分片直接送达参数存储，传输和放置均不使用 SM。TIDE-RS 直接消费逐参数 bf16 梯度，并使用拷贝引擎和短生命周期线程块（CTA）进行节点内累加、使用 NVSwitch 进行跨节点归约，将其归约为 fp32 分片（这是 NCCL 不提供的混合精度模式）。两阶段流水线将梯度读取与网络推进分离；Slot-Reuse 可选地将梯度暂存到腾空的全收集槽位中。在 64 个 GPU 上，在 Llama-3.1 70B、Wan2.2 和 Qwen3-30B-A3B 上，TIDE 相比 Stock FSDP2 将单步时间最多降低 27.1%，相比 FSDP2+SymmMem 最多降低 6.0%。它将 reduce-scatter 的 SM 时间降低为原来的 1/12.5–1/14.5，并将对并发计算的干扰最多降低一个数量级。在每 GPU 输出大小固定时，其 reduce-scatter 缓冲区从 16 到 64 个 GPU 几乎保持恒定；其峰值内存比 FSDP2+SymmMem 低最多 4.7 GiB，并且在 Wan2.2 上启用 Slot-Reuse 时低于 Stock FSDP2。

## Abstract
Fully Sharded Data Parallelism (FSDP2) maintains parameters and gradients as per-parameter tensors, whereas its collective path operates on flat, rank-major buffers. Converting between these layouts copies all-gather outputs into parameter storage and packs gradients into full-group fp32 buffers. Layout conversion alone accounts for 6.4% of step time in Llama-3.1 70B training at 8K tokens per GPU. Communication kernels impose a second cost: a default NCCL reduce-scatter can slow a concurrent GEMM that would otherwise complete in a single wave by 69%. We present TIDE, a set of zero-copy collectives built on public NCCL 2.31+ APIs. TIDE preserves FSDP2's per-parameter storage and compute kernels while folding layout placement into collective addressing. TIDE-AG delivers shards directly to parameter storage using NVSwitch multicast and paced recursive-doubling RDMA, with no SMs used for transport or placement. TIDE-RS consumes per-parameter bf16 gradients directly and reduces them into fp32 shards (a mixed-precision mode that NCCL does not provide) using copy engines and short-lived thread blocks (CTAs) for node-local accumulation and NVSwitch for cross-node reduction. A two-phase pipeline separates gradient reads from network progress; Slot-Reuse optionally stages gradients in vacated all-gather slots. On 64 GPUs, TIDE reduces step time by up to 27.1% relative to Stock FSDP2 and 6.0% relative to FSDP2+SymmMem across Llama-3.1 70B, Wan2.2, and Qwen3-30B-A3B. It reduces reduce-scatter SM time by factors of 12.5-14.5 and cuts interference with concurrent compute by up to an order of magnitude. Its reduce-scatter buffer remains nearly constant from 16 to 64 GPUs at a fixed per-GPU output size, and its peak memory is up to 4.7 GiB below FSDP2+SymmMem's and, with Slot-Reuse on Wan2.2, below Stock FSDP2's.

  1. **布局转换与打包**：AG 输出需 `split_with_sizes_copy` 拷入参数存储（2NS 字节 HBM 流量在关键路径上）；反向需 `_chunk_cat` 把 bf16 梯度切片、补零、升精度、打包成瞬态全组 fp32 缓冲（B_pack = 2NS_grad ~ 4NS_grad）。Llama-3.1 70B、8K tokens/GPU 下，仅此一项占单步 **6.4%（0.33 s）**。此外 H2D 元数据拷贝会与激活预取发生队头阻塞。
